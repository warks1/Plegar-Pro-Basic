# Plegar Pro — Beta Final CAD

Base: Plegar Pro Ultimate v6 / v49.5 cumulative.

## Correcciones de esta beta
- Matrices y punzones separados y seleccionables independientemente.
- Biblioteca ampliada de matrices y punzones, conservando las familias anteriores.
- Ejemplo OMEGA: 4 alas de 50 mm con sentidos +90°, -90°, -90°, +90°.
- Pantalla de carga de 5 segundos.
- Botonera flexible para evitar solapamientos en PC, tablet y móvil.
- Selección de utillaje sincronizada con la operación activa.

Las cotas de herramientas de fabricante que no proceden de un plano/catálogo verificado se marcan como familia y deben comprobarse antes de producción.
