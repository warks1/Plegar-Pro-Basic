# Plegar Pro Beta 20 — Omega / perfiles reales

Base: Beta 20 Omega. Se conservan los módulos y la interfaz existentes.

## Añadido
- Perfiles de punzones y matrices generados desde parámetros documentados.
- Perfiles MECOS 30° 11.904, 11.911, 11.914 y 11.916 con H/R y cotas de hombro/cuerpo tomadas del catálogo Red Line/Tecnostamp.
- MECOS 11.810 H200 y 11.880 H150 según catálogo.
- Perfiles AMADA AFH 814, 817, 846, 841 y 831.
- Matrices AMADA AFH 0706, 0717, 0726, 0746, 0776, 0796, 0871 y 0881.
- Geometría del mismo perfil usado para representar la herramienta y para la comprobación de interferencia.
- Estado de dato: DOCUMENTADO u ORIENTATIVO.

## Nota de ingeniería
Los datos documentados se basan en catálogos/plano publicados. Cuando el plano no aporta todas las coordenadas necesarias para reconstruir el contorno completo, el motor usa una reconstrucción paramétrica y lo marca como tal; no se presenta como CAD oficial del fabricante.

Fuentes principales:
- MECOS/Tecnostamp Red Line AMADA-PROMECAM.
- MECOS General Tooling Catalogue 2022.
- AMADA AFH Bending Tools Catalogue 2024.
