# Plenetal Pro Basic — Collision Beta

Beta funcional inicial centrada en la simulación geométrica de colisiones.

Incluye:
- Vista 2D de sección con chapa, punzón y matriz.
- Vista 3D CAD/CAM interactiva (girar y zoom).
- Selección de máquina: TRUMPF TruBend V85 / Bystronic 100 t.
- Selección inicial de punzones y matrices MECOS por ángulo/V.
- Grosor, ángulo, ala y carrera.
- Simulación de carrera y aviso visual SIN COLISIÓN / COLISIÓN.
- Secuencia de 5 pasos para la Omega 50/80/120/80/50.
- Cotas visuales básicas.

IMPORTANTE:
Esta es la beta de validación del motor visual. Las geometrías de herramienta incluidas son parámetros de prueba y NO deben utilizarse para fabricar una pieza ni para validar un programa CNC. La siguiente fase debe sustituirlas por geometrías y cotas verificadas directamente contra los planos/catálogos oficiales de cada referencia MECOS/AMADA y por modelos reales de cada máquina.

La vista 3D utiliza Three.js desde CDN, por lo que necesita conexión a Internet al abrir index.html.
